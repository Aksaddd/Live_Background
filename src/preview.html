Install on your PC

  1. Install Lively Wallpaper (free) from the Microsoft Store or its GitHub page, rocksdanister/lively.
  2. Download MistyRidge-lively.zip from the wallpaper/mist/dist folder on your GitHub branch.
  3. In Lively, click + (Add wallpaper) and drop the zip in.
  4. Open Lively's Settings → Wallpaper and set the arrangement to Span.
  5. Click the Misty Ridge tile. To tune it, right-click the tile and choose Customise.

What you are looking at

The fog in the photo was measured pixel by pixel, so the animation knows how far away each tree is. It thickens and thins that same fog over time, which keeps the mist behind the near trees and denser down the valleys. Each monitor gets its own mist, blowing up toward the ridge in the middle, so the two sides never move as mirror copies. The motion loops every 30 minutes with no visible seam.
